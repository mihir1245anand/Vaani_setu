# Contributing to Vaani-Setu

Thank you for your interest in contributing to Vaani-Setu!

## Code of Conduct
Please be respectful, collaborative, and mindful of linguistic accessibility for all users.

## Development Workflow
1. Fork and clone the repository.
2. Create a feature branch: git checkout -b feat/your-feature-name.
3. Test locally using 
pm start or any static HTTP server.
4. Verify changes in multiple languages using the language selector.
5. Submit a Pull Request against main.

## Contribution Standards
- Write semantic HTML and accessible CSS.
- Ensure all new user-facing strings have entries in src/js/i18n.js.
- Add meaningful commit messages following Conventional Commits format.
