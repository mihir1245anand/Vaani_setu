# Vaani-Setu Prototype

A self-contained hackathon demo based on the supplied Vaani-Setu requirements.

## Run
Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.

The voice demo uses browser Speech Recognition when available and falls back to text.
All scheme records are mock prototype data; no government application is submitted.
