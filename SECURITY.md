# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within Vaani-Setu, please do not open a public issue.
Instead, email security reports to **raghavanand034@gmail.com**. All legitimate reports will be addressed promptly.
