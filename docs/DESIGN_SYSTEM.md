# Vaani-Setu Design System & Tokens

## Color Palette
- --color-primary-navy: #0f2b48 (Trust & Governance)
- --color-accent-amber: #e8871e (Accessibility & Warmth)
- --color-surface-light: #f8fafc (Background Canvas)
- --color-surface-white: #ffffff (Card Container)
- --color-text-dark: #1e293b (High Contrast Readability)
- --color-text-muted: #64748b (Secondary Metadata)
- --color-success-green: #10b981 (Eligibility Matched)

## Typography
- Font Family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
- Fallback Font: Noto Sans for Indian Scripts (Devanagari, Bengali, Telugu, Tamil, Gujarati, etc.)
