---

## 🌟 Key Features
- 🗣️ **Multimodal Voice Assistant**: Speak in your native language or type questions naturally.
- 🌐 **12 Indian Regional Languages**: Seamless instant translation across Hindi, Bengali, Telugu, Marathi, Tamil, Gujarati, Urdu, Kannada, Odia, Malayalam, Punjabi, and English.
- 📋 **Dynamic Eligibility Engine**: Smart matching based on age, income, state, occupation, and demographics.
- 📝 **Interactive Readiness Checklist**: Step-by-step required document checklist and direct application guidance.
- 📱 **Mobile & PWA Ready**: Fast, responsive, accessible, and lightweight.

## 💻 Local Development

1. **Clone repository:**
   `ash
   git clone https://github.com/raghav1245anand/Vaani_setu.git
   cd Vaani_setu
   `

2. **Run with Node.js:**
   `ash
   npm start
   `
   Or run using any static server (Python/LiveServer):
   `ash
   python -m http.server 3000
   `

3. Open http://localhost:3000 in your browser.
