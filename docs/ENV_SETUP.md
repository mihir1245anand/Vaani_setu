# Local Environment Setup & Debugging Guide

## Prerequisites
- Node.js 18.x or higher
- Modern Chromium / WebKit based browser

## Setup Steps
`ash
npm install
npm run dev
`

## Troubleshooting
- **Microphone Access**: Ensure your browser allows microphone permissions on localhost or HTTPS.
- **Port Conflict**: If port 3000 is occupied, set PORT=5500 npm start.
